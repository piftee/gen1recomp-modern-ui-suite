# Third-party notices

## NikoIchu — 1-bit Pixel Icons

The Modern Start Menu component uses 31 selected native 16×16 symbols from
NikoIchu's **1-bit Pixel Icons** v1.2 collection:

<https://nikoichu.itch.io/pixel-icons>

The collection is released under the Creative Commons CC0 1.0 Universal
public-domain dedication. The selected source coordinates are preserved
exactly; packaging changes only the black/white canvas into transparent
one-colour game sprites.

The Pokémon party Poké Ball is original artwork made for this mod and is not
part of NikoIchu's collection.

## Other credits

Typed Move Colors includes settings-submenu and Vibrant-palette work originally
contributed by Haseo. Pokémon interface concepts and the backpack reference are
derived from user-supplied references to the Pokémon games; no ROM assets are
included beyond data extracted at runtime by Gen1Recomp's normal workflow.
