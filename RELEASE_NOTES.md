# Modern UI Suite 0.1.21

Fixes washed-out Pokémon colours when using Crystal Animated Sprites with
Shiny Visuals. Gen 2 Pokédex previews, party summaries and PC portraits now
retain the companion's authored colours. Shiny variants and animations are
preserved, including while Crystal's native entrance animation is active.

Native grayscale artwork continues to use its cartridge palette.

Install this ZIP in place of the previous Modern UI Suite version and keep
Crystal Animated Sprites with Shiny Visuals enabled.
