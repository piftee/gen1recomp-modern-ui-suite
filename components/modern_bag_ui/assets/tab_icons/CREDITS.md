# Bag category tab glyphs

The pixel masks in `tab_icons.lua` were authored for this update on
18 October 2026. They are original code-defined interface glyphs, not extracted
game sprites or images from the Openmon pack. No external artwork was used.

The family uses 12×12 masks, except for the native 15×9 key. Its round bow
and centred shaft are deliberately redrawn with one-pixel contours, providing
a middle size between the earlier 12×7 and 18×11 versions without scaled strokes.

The set contains a backpack (All), drawstring pouch (Items), capped medicine
bottle, capture ball, optical disc, horizontal key, and a berry compatibility
symbol. Filled, opaque pixel cells and a shared outline/fill/highlight/shadow
palette keep their shapes crisp at the tab's native display size. The bottle
cap uses the contour ink instead of the selected tab's background ink.
